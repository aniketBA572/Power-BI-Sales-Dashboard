# Power BI Sales Dashboard

## 📌 Project Overview
This project is an interactive Power BI dashboard designed to analyze sales performance and business insights using data visualization techniques.

## 📊 Features
- Sales Analysis
- Profit Tracking
- KPI Dashboard
- Interactive Filters
- Region-wise Performance

## 🛠 Tools Used
- Power BI
- Excel
- DAX
- Data Visualization
